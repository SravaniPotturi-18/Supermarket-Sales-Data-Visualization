# Supermarket Sales Data Visualization

## Project Overview

This project focuses on analyzing supermarket sales data and creating an interactive dashboard using Microsoft Power BI.

The objective was to transform sales data into meaningful visualizations and communicate business insights through data storytelling.

## Objective

- Analyze supermarket sales performance
- Create meaningful visualizations
- Identify product, city, branch, and customer patterns
- Present key findings through a Power BI dashboard
- Practice data storytelling and dashboard design

## Dataset

The dataset contains 1,000 supermarket sales transactions with information about:

- Gender
- Invoice ID
- Branch
- City
- Customer Type
- Product Line
- Unit Price
- Quantity
- Tax 5%

## Tool Used

- Microsoft Power BI Desktop

## Dashboard

The dashboard includes:

- Total Sales
- Total Quantity Sold
- Total Tax
- Average Unit Price
- Sales by Product Line
- Sales by City
- Sales by Customer Type
- Sales by Gender
- Sales by Branch

## Key Business Insights

- Total sales were approximately **$351.5K** from **5,510 units sold**.
- **Fashion Accessories** was the highest-performing product line.
- **Naypyitaw** recorded the highest sales among the three cities.
- **Member customers** contributed slightly higher sales than Normal customers.
- **Female customers** generated higher sales than male customers.
- **Branch C** recorded the highest sales among the three branches.
- The average unit price was approximately **$55.67**.

## Project Outcome

This project helped develop practical skills in:

- Data Visualization
- Power BI Dashboard Development
- KPI Creation
- Business Analysis
- Data Storytelling
- Dashboard Design
- Communicating Business Insights

## Conclusion

The project demonstrates how raw sales data can be transformed into meaningful visual insights using Power BI. The dashboard helps identify sales performance across products, cities, branches, customer types, and genders, supporting better business understanding and decision-making.
